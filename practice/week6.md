# 6주차 실습 기록
## 사용한 에셋
- player.png, 출처:핀터레스트
- shoot.mps, 출처:freesound.org
## 사용한 ai 프롬포트 요약
- 1. 고블린 이미지 넣기 관련 프롬프트
- pygame에서 스프라이트 시트(고블린 이미지)를 불러와서 애니메이션으로 사용하는 방법 알려줘
- 하나의 png 이미지에서 여러 프레임을 잘라서 사용하는 코드 짜줘
- 캐릭터 방향(좌우)에 따라 이미지 반전되게 하는 방법 알려줘
- 특정 키 입력 시 공격 애니메이션 실행되게 만들어줘
- 캐릭터가 멈춰있을 때, 이동할 때, 공격할 때 각각 다른 애니메이션 나오게 구현해줘
- 2. 파일 경로 / 폴더 구조 문제 프롬프트
- pygame에서 이미지 파일이 안 불러와질 때 경로 설정 방법 알려줘
- 상대경로랑 절대경로 차이랑 pygame에서 어떤 걸 써야 하는지 설명해줘
- 프로젝트 폴더 구조를 어떻게 잡아야 안정적인지 알려줘
- assets/images 같은 폴더 구조 기준으로 파일 불러오는 코드 짜줘
- 이미지 파일이 있는데도 오류 나는 이유랑 해결 방법 알려줘
3. 사운드 추가 관련 프롬프트
pygame에서 mp3 또는 wav 사운드 넣는 방법 알려줘
특정 이벤트(예: 폭탄 경고, 충돌, 아이템 획득) 발생 시 효과음 재생되게 만들어줘
사운드 볼륨 조절하는 방법 알려줘
게임 시작할 때 배경음악 반복 재생하는 코드 짜줘
효과음 여러 개 동시에 겹치지 않게 관리하는 방법 알려줘
## ai 답변에서 도움이 된 것
- 내가 미처 알아채지 못한 버그나 코드의 문제점, 개선 방법을 알게 되어 코드 작성에 도움을 줌
## ai 답변을 수정하서나 버린 것
- 이상한 코드를 주거나, 맥락에 맞지 않는 주제를 꺼내서, 그 답변은 버림
